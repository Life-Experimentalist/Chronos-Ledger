# chronosledger-client

Typed Rust client for the [Chronos Ledger](https://github.com/Life-Experimentalist/Chronos-Ledger) REST API, generated from the project's OpenAPI document and built on `reqwest` and `tokio`. Rust 1.88 or newer.

```sh
cargo add chronosledger-client
```

The crate is on crates.io from 0.18.0. Usage and examples: [docs/sdks/rust.md](https://github.com/Life-Experimentalist/Chronos-Ledger/blob/main/docs/sdks/rust.md).
