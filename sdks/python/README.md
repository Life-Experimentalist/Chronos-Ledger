# chronosledger-client

Typed Python client for the [Chronos Ledger](https://github.com/Life-Experimentalist/Chronos-Ledger) REST API.

Usage and examples: [docs/sdks/python.md](https://github.com/Life-Experimentalist/Chronos-Ledger/blob/main/docs/sdks/python.md).

```bash
pip install chronosledger-client
# or
uv add chronosledger-client
```

The package appears on PyPI from 0.18.0. Until then, install it from a checkout with `pip install ./sdks/python`. The import name is `chronosledger_client`.
